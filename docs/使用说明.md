# 岚屏工作台

适配爱国者星璨岚屏显版的 6 英寸、1480 × 720 机箱屏。目标 USB 设备为 `1D6B:0113`，系统为 Windows x64。已在 V1.0.7 固件的实物屏上确认显示测试画面。

## 打开与投屏

1. 完整解压 Windows 压缩包，双击 `LanScreenStudio.exe`。保留同一目录下的 `resources` 和其他文件。
2. 在预览上方选择「背景画面」「音乐歌词」或「专注计时」。在背景模式可选内置画面，或导入本地 PNG、JPG、WebP、GIF 或 MP4。时钟和硬件信息会显示在画面底部。
3. 从系统托盘退出正在控制屏幕的 AIGO，然后点击窗口顶部的「开始投屏」。USB 连接中断时，工作台会自动重连，连接恢复后继续投屏。点击「停止投屏」可结束投屏和重连，随后可以重新打开 AIGO。
4. 关闭窗口会把工作台收进系统托盘，已经开始的投屏会继续。双击托盘图标，或从右键菜单选择「显示工作台」打开窗口。托盘菜单也可以开始或停止投屏。选择「退出工作台」可停止投屏并退出程序。
5. 「保存画面」将预览保存为一张 1480 × 720 的 PNG，也可拿到 AIGO 的「上传背景」里使用。

## 音乐模式

- 切换到「音乐歌词」，在「播放器」选择网易云音乐，或自动跟随 Windows 的媒体会话。网易云音乐需要开启「设置 → 常规 → 系统 → 开启 SMTC」。选择固定播放器后，工作台会记住该选择。
- 音乐画面左侧显示封面、曲目信息、播放进度和频谱，右侧显示歌词。背景与频谱颜色随封面变化。打开「实时频谱」后，可在「频谱来源」选择「系统混音」或「当前播放器」。「系统混音」显示 Windows 默认输出设备上的声音，包含其他应用。「当前播放器」只采样当前播放器的音频，要求 Windows 内部版本号为 20348 或更高。系统版本低于要求，或当前播放器无法单独采样时，侧栏会显示提示，机箱屏的频谱区域留空。
- 工作台优先采用 Windows 媒体会话中的播放进度。网易云会话未提供进度时，工作台会读取本机近期的网易云播放记录，匹配曲目后按播放、暂停和定位事件自动对齐。同一首歌的进度短暂中断时，工作台会沿用最近的有效进度，暂停时定格歌词。缺少进度时会先显示开头三行作为预览，可在「对齐到播放器进度」填入播放器显示的分:秒。
- 网易云音乐默认自动读取同步歌词和可用的翻译。工作台优先用已确认的网易云歌曲 ID 查询和绑定歌词，也可按曲目信息搜索。查询无需登录。自动取词遇到暂时的网络故障或查询限流时会稍后重试。可关闭「网易云自动取词」，再按需点击「查找歌词」。其他播放器可用 LRCLIB 查找。
- 匹配多个歌词版本时，可按专辑和总时长选择，也可通过「导入 LRC」加载本地歌词。手动选取或导入的歌词和调整过的歌词偏移会按曲目保存在本机。 沿用旧版无歌曲 ID 的保存记录时，可在版本列表选择「旧版保存」，再点击「使用」。「歌词延后（毫秒）」填正数会延后歌词，填负数会提前。
- 在「歌词布局」选择「双语滚动」可高亮当前行并显示可用的翻译。选择「单行大字」可放大当前歌词，并保留歌名和播放进度。

## 专注模式

- 选择「专注计时」后，画面主区显示当前任务、倒计时和进度，右侧显示已完成轮次及下一阶段。
- 专注和休息默认是 25 分钟和 5 分钟。开始前可以更改时长。计时可暂停、继续和重置。到点后在工作台点击「开始休息」或「开始专注」，就会进入下一阶段。

## 素材与刷新

MP4 和 GIF 可在软件里预览并循环。机箱屏通过 USB 逐帧接收压缩画面，刷新速度随画面复杂度变化。建议用静态背景、时钟、状态面板或节奏较慢的动画。MP4 以常见的 H.264 编码最容易预览。

内置画面为本项目绘制。以下公开素材也可单独下载后导入。

- 东京雨夜。[MotionBGs](https://motionbgs.com/rainy-nights-in-tokyo)
- 未来城市公路。[Mixkit](https://mixkit.co/free-stock-video/futuristic-virtual-city-highway-loop-video-31534/)
- 云海飞行。[Mixkit](https://mixkit.co/free-stock-video/flight-above-the-cloud-level-loop-video-32991/)

## 从源码运行

在源码包的目录中使用 Node.js 24 和 npm。

```powershell
npm ci
npm start
```

`npm test` 验证协议帧和播放控制。 `npm run package:windows` 构建便携版，生成目录位于 `build`。
